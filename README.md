# Wanderlast



/* -- Wanderlast -- */

Wanderlast is a travel booking platform that connects travelers with local experts and travel guides. Our platform offers a wide range of destinations, from the most popular to the least visited, and provides users with a hassle-free booking experience.

## Features

- User-friendly interface
- Search for destinations and activities
- Booking and payment system
- Reviews and ratings
- Social media integration
- Mobile responsiveness

## Getting Started

To get started with Wanderlast, follow these steps:

1. Clone the repository:

```bash
git clone https://github.com/your-username/wanderlust.git
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
